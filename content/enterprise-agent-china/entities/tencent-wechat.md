# Tencent WeChat

## Overview

WeChat is China's dominant super-app with 1.3B+ monthly active users. On March 22, 2026, Tencent integrated OpenClaw agents directly into WeChat, giving over 1 billion users instant access to AI agents through a familiar chat interface.

## Details

**Platform Stats**
- 1.3B+ monthly active users
- 80%+ smartphone penetration in China
- Average user spends 90+ minutes per day in WeChat
- Ecosystem: Payments, mini-programs, official accounts, work chat

**WeChat ClawBot Integration (March 2026)**
- **Launch date**: March 22, 2026
- **Distribution**: Instant access for 1B+ users
- **Interface**: Simple contact in chat list, send tasks via text
- **Use cases**: Shopping, booking, customer service, information lookup
- **Technology**: OpenClaw framework, Hunyuan LLM

**Agent Capabilities**
- **Shopping**: Product search, price comparison, order placement
- **Services**: Restaurant booking, ticket purchase, appointment scheduling
- **Customer service**: Query handling, complaint resolution, refund processing
- **Information**: News, weather, traffic, local services
- **Payments**: WeChat Pay integration for transactions

**Enterprise WeChat (WeCom)**
- Separate app for business communication
- 180M+ users across 5.5M+ organizations
- Agent use cases: Meeting scheduling, document collaboration, approval workflows
- Private deployment option for large enterprises

**Technology Stack**
- **LLM**: Hunyuan (Tencent's proprietary model)
- **Agent framework**: OpenClaw (open-source)
- **Infrastructure**: Tencent Cloud
- **Integration**: WeChat SDK, mini-programs, official accounts

**Competitive Advantages**
- **Unmatched distribution**: 1.3B users, no app download needed
- **Ecosystem lock-in**: Payments, social, services all in one app
- **User trust**: WeChat is essential infrastructure in China
- **Government relations**: Strong ties to Chinese government

**Strategic Implications**
- **Agent-as-feature**: Agents embedded in existing super-app, not standalone
- **Speed and reach**: China's strategy vs. US proprietary ecosystems
- **Open source**: OpenClaw enables rapid ecosystem development
- **Platform power**: Tencent controls distribution to 1B+ users

**Regulatory Considerations**
- **Content moderation**: All agent outputs subject to censorship
- **Data localization**: User data stored in China
- **Government access**: Compliance with national security laws
- **MLPS 2.0**: Multi-level protection scheme compliance

**Market Position**
- #1 super-app in China
- Main competitor: Alipay (payments), DingTalk (enterprise)
- Differentiation: Social network effects, ecosystem breadth
