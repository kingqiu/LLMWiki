# ByteDance Coze

## Overview

Coze is ByteDance's consumer-focused agent platform with 50M+ users on Douyin (Chinese TikTok). It represents the "agent-as-feature" strategy, integrating agents into existing super-apps rather than building standalone agent products.

## Details

**Platform Stats**
- 50M+ users on Douyin integration
- 36M MAU for Doubao assistant (leading consumer agent in China)
- Integration with Feishu (ByteDance's enterprise collaboration platform)
- Expansion to TikTok for international markets

**Coze Features**
- **No-code agent builder**: Visual workflow designer for non-technical users
- **Plugin marketplace**: 1000+ pre-built plugins for common tasks
- **Multi-modal**: Text, image, voice, video understanding
- **Personalization**: Learns user preferences over time
- **Social integration**: Share agents with friends, viral distribution

**Doubao Assistant**
- Leading consumer agent in China with 36M MAU
- 36M MAU gap over third-place Kimi
- Use cases: Content creation, social media management, personal productivity
- Integrated into Douyin, Feishu, TikTok

**Enterprise Expansion**
- Feishu (Lark) integration for internal workflows
- Custom agents for enterprise use cases
- Private deployment option for large customers
- Focus: Content generation, customer service, marketing automation

**Technology Stack**
- **LLM**: Proprietary model (rumored to be based on Llama)
- **Agent framework**: Coze SDK, compatible with OpenClaw
- **Infrastructure**: ByteDance Cloud
- **Integration**: REST APIs, webhooks, Feishu SDK

**Competitive Advantages**
- **Distribution**: Instant access to 50M+ Douyin users
- **Content focus**: Optimized for video, image, social media content
- **Viral growth**: Social sharing drives organic adoption
- **Youth market**: Strong appeal to Gen Z users

**Weaknesses**
- **Enterprise security**: Limited compliance features vs. DingTalk
- **B2B sales**: Weak enterprise sales team vs. Alibaba, Tencent
- **Government relations**: ByteDance faces regulatory scrutiny

**Market Position**
- #1 consumer agent platform in China
- #3 enterprise collaboration (behind DingTalk, Feishu)
- Differentiation: Content creation, social integration, youth appeal

**Pricing**
- Free tier: Basic agent building and usage
- Pro: ¥29/month for advanced features
- Enterprise: Custom pricing with private deployment
