# NVIDIA

## Overview

Dominant GPU ecosystem provider. Jensen Huang frames AI as fundamental infrastructure ("five-layer cake"). In the agent space, NVIDIA launched OpenShell — a Harness product with kernel-level security.

## Key Contributions

- **OpenShell**: Agent Harness with Landlock and Seccomp kernel-level security (announced at GTC 2026)
- **Five-layer cake**: Energy → Chips → Infrastructure → Models → Applications
- **DGX Systems**: Reference hardware for AI training/inference
- **Triton Inference Server**: Optimized model serving
